Salin isi data.json

Copy semua teks di kotak bawah, buka file data.json di GitHub (bukan index.html), klik pensil, hapus semua isinya, tempel ini, lalu Commit. Ini file kecil terpisah, jadi gampang & aman — gak perlu cari-cari baris di file besar lagi.
